Why Jarvis

Small, private and made for everyone

Private by design

Memory is a single JSON file you own, or RAM only with --no-memory. Mood check-ins are never written to disk.

Zero dependencies

Just the Python 3.10+ standard library, with nothing to compile. You can read exactly how every answer was produced.

Accessible

Read and write braille, learn ASL signs and fingerspelling, and hear replies aloud with --speak.

Safety first

Crisis support is checked before any other skill, so messages about self-harm get help lines first. Emergency numbers cover {{country_count}} countries and territories, and anything that acts in the real world is opt-in.

Cloud only when you ask

Only two skills ever use the network. answer starts a GitHub Copilot cloud session (default model {{cloud_model}}), and only once you provide a token.

A terminal that shines

Colour, a banner and readline-safe prompts in a real terminal. Plain text in pipes, with NO_COLOR or with --color never.

Get started

Install in one line

You need Python 3.10 or newer. Nothing else.

  1. Install from GitHub

    pip install git+https://github.com/charles2ke/jarvis.git

  2. Start a session

    jarvis

  3. Or ask a single question

    jarvis "what time zone is Japan in?"

The jarvis package on PyPI is an unrelated project, so install from GitHub as shown. To work on Jarvis itself, clone the repository and run pip install -e .

Fresh and sourced

Checked against trusted sources

For v{{version}}, the built-in facts were reviewed against the references below. The data ships with Jarvis so it works offline, but it is a snapshot, so confirm anything critical locally.

  • Population

    UN World Population Prospects 2024, medium-variant figures for mid-2026.

  • City notes

    Lagos and São Paulo descriptions corrected using UN World Urbanization Prospects 2025.

  • Time zones

    Every zone and offset checked against the IANA Time Zone Database 2026f.

  • Currencies

    Checked against Unicode CLDR 49.

  • Maritime safety

    IMO SOLAS chapter IV, as modernised on 1 January 2024.

  • Emergency numbers

    Compared with Google's libphonenumber v9.0.43. Where they disagreed, checked against current UK, US, Australian and Irish government travel advice.
